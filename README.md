# 火箭三维探索馆

给孩子看的中文三维火箭科普网页。打开就是可以拖动的三维火箭，不是文字目录，也不是照片墙。

页面地址（合并并开启 GitHub Pages 之后）：

https://dannywang0822.github.io/rocket-explorer-3d/

## 能看什么

- **9 种独立三维外形**：美国土星五号（阿波罗构型）、猎鹰九号（卫星整流罩）、重型猎鹰；中国长征二号 F（载人型）、长征五号 B、长征七号；苏联／俄罗斯联盟 FG、质子 M／微风 M、苏联 N-1。
- 左右拖动改方位，上下拖动改俯仰；滚轮、滑杆和双指缩放；复位；自动旋转开关；斜前方、背面、顶部、底部喷口；线框。手机用单指拖动。
- 每种外形旁边有真实照片、中文观察说明和公开来源。
- 25 个实拍展项可以放大、点选部位、两张对照。另有 1 张 NASA DART 照片，专门对照猎鹰九号的卫星罩三维，不放进 25 张图墙。
- 完整目录 **394 条**（主库 368，实验／探空精选 26，59 个资料目录组）。可以按中文、英文和别名搜索。条目数不是独立工程家族数。没有建模的条目会写明「尚未建立三维模型」。

这些三维外形是**依据公开尺寸重建的简化科普模型，不是官方工程模型**，也不表示精确内部结构，更没有覆盖全部 394 条目录。资料截至 **2026年11月8日（北京时间）**。星舰 Block 3 近期记录和 HASTE 轨道用途仍待独立全文复核。

## 发布

`.github/workflows/pages.yml` 在推送到 `main` 时构建并部署 GitHub Pages。仓库需要在 Settings → Pages 中把 Source 设为 **GitHub Actions**。站点根路径是 `/rocket-explorer-3d/`，页面不需要后端，也不使用密钥。

## 照片

26 张图按各自许可随仓库提供，并在页面「小课堂」里逐张署名。许可包括公有领域、CC0、CC BY 和 CC BY-SA，不能笼统说成同一种许可。原文件页链接保留。若本地文件加载失败，页面会改用 Wikimedia 原链。

署名明细见 [CREDITS.md](CREDITS.md)。许可核对材料见 `data/photo-license-evidence.json`。

本仓库自行编写的网页代码采用 MIT 许可，见 [LICENSE](LICENSE)。**该许可不覆盖照片，也不把三维外形变成官方模型。**

## 数据从哪来

型号尺寸和轮廓来自已经核对过的公开资料，例如 NASA、SpaceX、中国载人航天、国家航天局、ESA、ILS，以及 N-1 的公开历史汇编。目录字段对照 GCAT。NASA 公开的 Saturn V 网格只做过可获得性调查，**没有**放进这 9 个模型，本页模型也不是 NASA 原模。
